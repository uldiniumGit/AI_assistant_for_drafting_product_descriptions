# Генератор карточек товаров

Небольшой Python CLI-проект для подготовки черновиков карточек КИП. Программа
читает данные товаров из JSON, отправляет их в OpenRouter и сохраняет ответ модели
в JSON. Если технических сведений недостаточно, карточка отмечает, что нужно
уточнить. Результат предназначен для проверки контент-менеджером, а не для
автоматической публикации.

## Установка и запуск

Нужен Python 3.10 или новее и API-ключ OpenRouter. Дополнительные библиотеки
устанавливать не требуется.

1. Склонируйте или скачайте проект и перейдите в его папку.
2. Создайте локальный файл конфигурации:

   ```powershell
   Copy-Item .env.example .env
   ```

3. Откройте `.env` и укажите свой ключ в `OPENROUTER_API_KEY`. При необходимости
   измените `OPENROUTER_MODEL` или `OPENROUTER_TIMEOUT`.
4. Запустите генератор:

   ```powershell
   python app.py
   ```

По умолчанию программа читает `products.json` и записывает результат в
`generated_products.json`. Файлы можно переопределить аргументами командной строки:

```powershell
python app.py other_products.json --format json --output other_result.json
```

Проверить входные данные без API-вызова можно так:

```powershell
python app.py products.json --validate-only --output -
```

## Примеры запуска

- `products.json` — входные данные двух примеров товаров: модуля МК110-224.8Д.4Р
  [М01] и GSM-модема ПМ01-24.АВ. В файле есть известные сведения из переданной
  выгрузки, включая производителя, тип, артикул, код, цену и ссылки.
- `generated_products.json` — примеры карточек для этих же двух товаров,
  полученные запуском проекта через OpenRouter. В них приведены SEO-заголовки и
  описания, ключевые характеристики, поисковые запросы, коммерческие блоки и
  пометки о недостающих данных.

Оба JSON-файла включены в проект и могут быть загружены на GitHub. Не помещайте в
репозиторий секреты: `.env` исключён из Git; для настройки используется
публикуемый шаблон `.env.example`.

## Файлы проекта

- `app.py` — запуск и аргументы командной строки.
- `config.py` — чтение настроек из `.env` и окружения.
- `openrouter.py` — запросы к API OpenRouter.
- `product_cards.py` — обработка товаров, промпт и проверка результата.
- `products.json` — примеры входных товаров.
- `generated_products.json` — примеры сгенерированных карточек.
- `.env.example` — пример конфигурации без API-ключа.
